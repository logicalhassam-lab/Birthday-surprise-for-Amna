# My Love's Dream

Create a romantic, magical birthday surprise website for my fiancée. This is a special one-page website (single page app) with the following details:

1. LOADING/INTRO SCREEN

- When the website first loads, show a beautiful animated loading screen for 3-4 seconds

- Display the text "A Magical Surprise, Crafted With Love, Just For You ✨" with elegant fade-in and glow animation

- Use a soft heartbeat or sparkle loading animation instead of a plain spinner

- Background should be a soft gradient (blush pink to lavender to soft red) with subtle floating hearts/sparkles in the background even during loading

2. COLOR PALETTE (IMPORTANT)

- This website is for a girl, so use soft, feminine, romantic colors

- Primary palette: blush pink, rose gold, soft lavender, warm cream, and deep red/maroon as accent

- Avoid harsh or dark colors, keep everything soft, dreamy and elegant

- Use gradients and soft shadows, not flat harsh colors

3. HERO SECTION (after loading screen)

- Full-screen hero section with her name and a romantic birthday heading like "Happy Birthday, My Love ❤️" in elegant cursive/script font

- Subheading with a sweet romantic message

- Background should have animated floating hearts, sparkles, and soft glowing particles moving slowly upward (like magic dust)

- Add small floating love icons (hearts, stars) scattered around, gently moving up and down (floating animation)

- Include a soft "Play Music" button (heart-shaped or music note icon) in a corner that plays a romantic background song on click (use royalty free romantic instrumental audio, autoplay muted then unmute on user interaction due to browser policies) with a toggle to pause/play

- Add a subtle animated background music visualizer or pulsing heart icon while music plays

4. ADDITIONAL SECTIONS (scroll down from hero)

- "Why I Love You" section with animated cards listing sweet reasons, each card has a heart icon and soft hover animation

- A photo gallery / memories section with placeholder images in heart-shaped or rounded frames with hover zoom effect

- A countdown timer counting down to her actual birthday moment or counting how many days you've been together (make it a placeholder I can edit)

- A "Love Letter" section styled like an open envelope/letter with a heartfelt message, elegant typography, decorative borders

- A wish/message section at the end with "My Love" styled in cursive glowing text, floating hearts animation around it, and a birthday cake icon with candle blow animation (optional, on click confetti/hearts burst)

5. ANIMATIONS

- Smooth scroll animations (fade in, slide up) as user scrolls to each section

- Floating hearts and sparkle particles continuously animating in the background throughout the site, not just hero

- Button hover effects with soft glow and scale up

- On page interactions, occasionally trigger small heart burst / confetti animation

6. TYPOGRAPHY

- Use elegant script/cursive font for headings (like "My Love", names, birthday wishes)

- Use a soft, readable modern font for body text

7. GENERAL

- Fully responsive (mobile and desktop)

- Smooth, magical, dreamy overall feel — like opening a digital love letter

- Add a small footer with a cute message like "Made with ❤️ just for you"
